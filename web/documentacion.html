📚 Documentación - El Vigilante

🚀 Instalación rápida

Agrega esta línea en el <head> de tu página web:

<script src="https://vigilante.onrender.com/vigilante.js?key=TU_API_KEY"></script>

🔑 Obtener una API Key

Regístrate en nuestro Dashboard para obtener tu API Key gratuita.

🎯 Eventos JavaScript

Puedes escuchar eventos para reaccionar a las detecciones:

// Cuando se detecta un humano
window.addEventListener('vigilante-humano', (e) => {
    console.log('Humano verificado', e.detail);
});

// Cuando se detecta un bot
window.addEventListener('vigilante-bot', (e) => {
    console.log('Bot detectado:', e.detail.motivo);
});

// Cuando hay error de conexión
window.addEventListener('vigilante-error', (e) => {
    console.error('Error:', e.detail);
});

❓ Preguntas frecuentes

¿Afecta el rendimiento de mi web?

No. El script pesa menos de 5KB y las verificaciones son asíncronas.

¿Qué pasa si El Vigilante falla?

El sistema tiene un "modo permisivo": si no puede conectar con nuestro servidor, permite el acceso para no afectar a tus usuarios reales.

¿Puedo personalizar la página de bloqueo?

Sí. En el Dashboard puedes configurar el estilo y mensaje de la página de bloqueo.

¿Es compatible con móviles?

Totalmente. Funciona en todos los navegadores modernos, incluyendo iOS y Android.
