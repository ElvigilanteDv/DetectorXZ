# 🚨 El Vigilante - Sistema Anti-Bots

Protege tu sitio web de bots automáticos, scrapers y ataques con una simple línea de código.

## ✨ Características

- 🛡️ **Detección inteligente** de bots (WebDriver, headless browsers, etc.)
- ⚡ **Ligero y rápido** (<5KB)
- 📊 **Dashboard en tiempo real**
- 🔑 **API Key personalizada**
- 🌐 **Compatible con cualquier sitio web**
- 📱 **Funciona en móviles**

## 🚀 Instalación

1. Regístrate en nuestro dashboard
2. Copia tu API Key
3. Pega esta línea en tu sitio web:

```html
<script src="https://vigilante.onrender.com/vigilante.js?key=TU_API_KEY"></script>
